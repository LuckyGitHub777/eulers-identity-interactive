# Euler's Identity — Interactive Mathematics

Explore the unit circle, matrix rotation, and relative phase through three small offline static experiences. Open `index.html` in a browser, or serve the folder with a local static server. Use `matrix.html` and `phase.html` for the companion laboratories.

**Scope:** Mathematical visualization, not a measurement of physical quantum systems. No backend, account, analytics or user-data submission is included. All site assets are locally served; no remote runtime dependency is required.
